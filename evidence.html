Quality & Assurance

Evidence Center

"If you cannot measure it, you cannot guarantee it."

Every precision optical component we deliver comes with evidence — not just a promise. Here you'll find the types of inspection data, material documentation, coating evidence, and quality certificates that accompany PhotonEdge orders.

Inspection Reports

Every precision component is inspected before shipment. We measure what matters and provide the data so you can verify compliance with your specification.

🔫

Interferometer Reports

✓ Surface flatness / surface figure measured at 632.8nm (ZYGO equivalent interferometer)
✓ Peak-to-valley (PV) and RMS values reported
✓ False-color interferogram with measurement parameters
✓ Transmitted wavefront error available for lenses and windows
Included with all precision-grade (λ/10 and tighter) orders. Available on request for standard grade.
🔍

Surface Quality Reports

✓ Dark-field inspection per MIL-PRF-13830B / ISO 10110
✓ Scratch and dig counts documented per optic
✓ Photographic evidence for laser-grade components
✓ Edge chip and chamfer verification
Standard on all laser-grade and precision orders. Summary report on standard grade.
🌈

Spectral / Coating Reports

✓ Transmission and reflection curves from PerkinElmer Lambda spectrophotometer
✓ Wavelength range: 190nm – 2500nm (UV-Vis-NIR)
✓ FTIR measurement available for MIR/LWIR coatings (2–20μm)
✓ Coating lot traceability and batch measurement data
Included with all coated optic orders. Sample-based measurement for production batches.
📏

Dimensional Inspection

✓ Diameter, thickness, and radius measurement with digital micrometers
✓ Optical comparator for edge profile and chamfer verification
✓ Centration / beam deviation measurement for lenses
✓ Wedge angle / parallelism measurement with autocollimator
100% dimensional inspection on every precision order. Dimensional data sheet included.

Material Documentation

Material properties fundamentally determine optical performance. We trace every component back to its source material and provide the documentation to prove it.

🧬

Material Certificate

✓ Material type, grade, and manufacturer identification
✓ Melt / ingot / boule number for traceability
✓ Chemical composition data (for crystalline materials)
✓ Impurity levels and homogeneity class
Provided with all precision and custom orders upon request.
🎯

Grade Certificate

✓ Optical homogeneity class (e.g., H1, H2, H3 per ISO 12123)
✓ Striae grade (A, B, C per MIL-G-17441)
✓ Bubbles and inclusions class
✓ Stress birefringence specification
Available for glass and crystalline materials from certified suppliers.
📈

Refractive Index Data

✓ n_d, n_F, n_C values (key wavelengths)
✓ Abbe number (V_d) and dispersion data
✓ Sellmeier coefficients on request
✓ Temperature coefficient (dn/dT) data available
Standard data from material datasheets. Custom measurement available for special projects.

Coating Evidence

Coatings determine how your optic performs in real use. We measure coating performance and provide evidence across the full spectral range of your application.

🔴

Transmission Curve

✓ Percent transmission vs. wavelength across the design band
✓ Measured with reference air baseline
✓ UV-Vis-NIR: 190–2500nm (Lambda spectrophotometer)
✓ MIR/LWIR: 2–20μm (FTIR spectrometer)
Included with all coated orders. Measured on witness sample from the same coating run.
🔵

Reflection Curve

✓ Reflectance vs. wavelength for HR and mirror coatings
✓ Specified angle of incidence (0°, 45°, custom)
✓ S and P polarization data for non-normal incidence
✓ Coating bandwidth and edge steepness verification
Provided with all mirror and high-reflection coating orders.
⚡

LIDT Data

✓ Laser Induced Damage Threshold test results
✓ 1-on-1 and S-on-1 test protocols (ISO 11254 equivalent)
✓ Pulsed (ns, ps, fs) and CW damage thresholds
✓ Test conditions documented (wavelength, pulse duration, rep rate)
Available for laser-grade coatings on request. Batch or design-level certification.

How Quality Verification Works

Quality isn't a single checkpoint at the end. It's built into the process at every step, with data captured at each stage.

1

Incoming Material

Material certificates verified against spec. Optical quality check before production.

2

In-Process Checks

Dimensional and surface quality checks at key process milestones. Photos shared with customers for custom orders.

3

Final Inspection

Full dimensional, surface quality, flatness, and spectral testing. 100% inspection on precision orders.

4

Documentation

CoC, inspection data, and material certificates packaged with shipment and available digitally.

5

Traceability

Every part traceable to material batch, coating run, and inspection record.
