Quality & Assurance

Engineering Evidence

Inspection and quality documentation available according to project requirements.

Documentation Categories

The following types of inspection and quality documentation can be provided depending on project requirements. Each category describes what it verifies and when it is typically provided.

1

Optical Inspection

What It Verifies
Verifies optical performance parameters including transmission, reflectance and wavefront error.
When It Is Provided
Provided when optical performance verification is required.
2

Dimensional Inspection

What It Verifies
Verifies mechanical dimensions including diameter, thickness, radius and center thickness.
When It Is Provided
Standard documentation for precision components.
3

Surface Quality

What It Verifies
Verifies surface scratch-dig rating per applicable standard.
When It Is Provided
Provided for components with surface quality requirements.
4

Flatness

What It Verifies
Verifies surface flatness using interferometric methods.
When It Is Provided
Provided when flatness specifications are agreed.
5

Coating Performance

What It Verifies
Verifies coating transmission, reflectance or LIDT performance.
When It Is Provided
Provided for coated optics when coating specs are confirmed.
6

Material Certification

What It Verifies
Confirms material specification, batch and optical constants.
When It Is Provided
Provided when material traceability is required.
7

Traceability

What It Verifies
Full material and process traceability from incoming material to finished component.
When It Is Provided
Available for projects requiring full lot traceability.
8

Certificate of Conformity

What It Verifies
Confirms conformity to agreed specifications and requirements.
When It Is Provided
Standard documentation for quality-managed projects.
9

Quality Documentation Package

What It Verifies
Comprehensive documentation package including all applicable inspection and material records.
When It Is Provided
Available for critical applications requiring complete documentation.

Documentation Overview

Summary of key documents, their purpose, and when they are provided.

Document Purpose When Provided
Material Certificate Confirms material specification When material traceability is required
Coating Report Confirms coating performance When coating specs are confirmed
Dimensional Report Confirms mechanical dimensions Standard for precision components
Surface Inspection Confirms surface quality When surface specs are agreed
Certificate of Conformity Confirms conformity to requirements Standard for quality-managed projects

Disclaimer: Documentation availability depends on project requirements and agreed specifications. Contact us to discuss what documentation is available for your specific application.
